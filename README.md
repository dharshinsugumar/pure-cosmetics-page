# Luxe Beauty Landing

Create a simple, premium cosmetics website frontend only using React.



Build a single-page responsive cosmetics landing page with:



- Clean luxury beauty design

- Soft beige, nude and white color palette

- Elegant typography

- Navbar with logo, Home, Products, About, Contact

- Hero section with cosmetics/beauty image, headline and Shop Now button

- Product section with 6 cosmetic products in simple cards showing image, name, price and Add to Cart button

- Category section: Skincare, Makeup, Lip Care, Hair Care

- Small About/Brand section

- Customer review section

- Newsletter/CTA section

- Simple footer



Use static/mock product data and images. No backend, database, authentication, payment, API or admin panel.



Keep the project lightweight, visually attractive, responsive and beginner-friendly. Focus only on the frontend UI.
